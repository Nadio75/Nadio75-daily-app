# Sprint 1 Retrospective – Book Tracer

## What went well
- User stories were rewritten with clear “As a / I want / so that” format and acceptance criteria.
- Story points were assigned using a consistent reference story.
- The Asana board now has real workflow states (To Do → In Progress → In Review → Done).
- Small scaffolding work was done so the board movement was honest.

## What didn’t go well
- The Display columns story (8 points) is still an epic-in-disguise and depends heavily on the other stories.
- Very little actual implementation happened inside the sprint — only empty feature folders were created.
- Acceptance criteria were written late (after the stories were already on the board).

## Concrete change for Sprint 2
Before the next sprint planning, split the “Display books in columns” story into two smaller stories:
1. Static 4-column board layout (independent).
2. Wire real book data into the columns.

This will make the board more realistic and reduce the risk of carrying a large, dependent story again.
