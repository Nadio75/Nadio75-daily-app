# Product Backlog

Rough, unrefined list of everything that might get built. Not yet estimated.

3. Delete a book from the tracker
4. Set a book's status (Want to Read / Reading / Finished / On Hold)

## Board & Columns

5. Display books grouped into their status columns
6. Move a book between columns (change its status)
7. Show a count of books in each column

## Search & Filter

8. Search books by title
9. Filter books by author
10. Filter books by genre

## Reading Progress

11. Add a progress percentage or page count to a book currently being read
12. Show progress visually on the book's card
13. Mark a book as finished, clearing its in-progress state

## Notes & Ratings

14. Add a personal note to a book
15. Add a star rating once a book is finished
