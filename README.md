# Book Tracker

Book Tracker is a personal reading board for keeping track of what I want to read, what I'm currently reading, and what I've finished built for readers starting with me, who want a simple visual way to see their reading life at a glance instead of losing track of half-read books across different apps and sticky notes. 

A Board is my whole reading life; a Column is a reading stage (Want to Read, Currently Reading, Finished, Abandoned); and a Card is a single book, holding its title, author, and whatever notes or progress I want to track as I read it.

## Purpose

See "Book Tracker is a personal reading board..." above the goal is a
single visual home for my reading list, replacing scattered notes apps and
sticky notes.

## Setup

This repo is currently in the planning stage, there is no runnable app
yet. To get set up:

1. Clone the repo: `git clone https://github.com/Nadio75/Nadio75-daily-app.git`
2. Read `docs/planning/epics.md` for the feature breakdown and
   `docs/planning/sprint-1-backlog.md` for what's actively being built.
3. No install step or dependencies are required yet, since there's no
   application code to run.
